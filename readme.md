# デジタルサイネージ（ライトプラン）
光井企画工学事務所 — 超局所IoTデジタルサイネージ with Google Analytics

## 概要
ChromeOS Flex搭載の余剰PC/ノートPCで動作する、手動起動許容型のサイネージです。
Google管理コンソールへの登録・ライセンス購入は不要です。

## サイトURL
https://resuscitationproject-lgtm.github.io/digital-signage01/

## 初期設定（お客様先での作業）

### 1. Chromeの起動ページを設定
1. Chromeを開き、右上の「⋮」→「設定」
2. 左メニュー「起動時」→「特定のページを開く」を選択
3. 「新しいページを追加」→ 上記サイトURLを入力

### 2. 画面が消えないようにする
1. 設定 →「電源」
2. 「電源接続時は自動的にスリープしない」を有効化
3. （ある場合）「画面のロック」もオフに近い設定にする

### 3. ロック解除を簡単にする
1. 設定 →「セキュリティとプライバシー」→「ロック画面」
2. PINコード（4桁程度）を設定しておくと復帰が速い

### 4. 動作確認
1. 一度サインアウト→サインインし直す
2. Chromeが起動時ページを開くことを確認
3. 画面を1回クリック（自動で全画面化されます）
4. 再生が始まればOK

## 日常の運用
- 電源ON → ロック画面 → PIN入力 → 自動でサイネージが開く → 1回クリックで全画面化
- 上部に「F11キーで全画面表示にしてください」という黄色いバナーが出る場合は、
  画面を1回クリックすると消えます（全画面化されたサイン）

## コンテンツの差し替え
`media/` フォルダの画像・動画を置き換えてGitHubにコミットすると、
最大6時間以内（自動リロード）に反映されます。すぐ反映したい場合は端末側でChromeを再起動してください。

## 再生順の変更
`index.html` 内の `CONFIG.mode` を書き換えます。

- `sequential` … 登録順にそのまま再生
- `shuffle` … 毎周ランダム（1周に1回は必ず表示）
- `weighted` … `weight` の数値に応じて表示頻度を調整
